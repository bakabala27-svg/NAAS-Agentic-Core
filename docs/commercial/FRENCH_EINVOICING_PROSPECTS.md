# قائمة المرشحين الفرنسيين للفوترة الإلكترونية — Prospect Dossier

> **الجمهور:** مالك العرض، مسؤول البحث التجاري، والمراجع الداخلي.
>
> **الغرض:** تحويل نتائج البحث العام إلى قائمة مرشحين فرنسيين قابلة للتأهيل، مع فصل صارم بين الإشارة العامة والفرضية والاتصال والبيع.
>
> **الحالة الحالية:** `PROSPECTING` / `DISCOVERY NOT STARTED`.
>
> **الحالة التجارية الحاكمة:** `GATE_C = ABSENT` — صفر عقود، صفر فواتير، صفر دفعات، وصفر مقابلات موثقة حتى لقطة البحث الحالية. لا يصف هذا الملف أي جهة بأنها عميل.
>
> **لقطة البحث:** 20 سبتمبر 2026. يجب إعادة التحقق من الصفحات قبل التواصل أو الاقتباس التجاري، خصوصاً الأسعار، المواعيد التنظيمية، وصف الخدمات، والبيانات القانونية.
>
> هذا الملف إضافة توثيقية، وليس عرضاً قانونياً أو ضريبياً، وليس دليلاً على امتلاك منتج فوترة إلكترونية فرنسي جاهز. يُقرأ مع [`FOREIGN_CURRENCY_OPERATING_SYSTEM.md`](FOREIGN_CURRENCY_OPERATING_SYSTEM.md)، ومع الحالة الحية في [`agent_reliability_hard_currency_truth.md`](../../.memory/agent_reliability_hard_currency_truth.md)، ومع [`WOD_BUYER_LAYER_OFFER.md`](WOD_BUYER_LAYER_OFFER.md). قواعد التوثيق في [`DOCUMENTATION_CONTRACT.md`](../DOCUMENTATION_CONTRACT.md) والفهرس في [`DOCUMENTATION_INDEX.md`](../DOCUMENTATION_INDEX.md).

## 1. تصحيح المصطلحات والحدود

### 1.1 ما هذه القائمة؟

هذه **قائمة prospects** مستخرجة من صفحات عامة. ظهور جهة في القائمة يعني فقط أن البحث وجد إشارة منشورة قد تجعلها مناسبة للاستكشاف. لا يعني ذلك أنها:

- طلبت الخدمة؛
- وافقت على الخدمة؛
- تعرف مقدم الخدمة؛
- أجرت مقابلة؛
- تلقت رسالة أو عرضاً؛
- وقّعت عقداً؛
- دفعت أي مبلغ؛ أو
- أصبحت عميلاً.

المصطلح المسموح في هذه المرحلة: `prospect`, `prospect qualifié à vérifier`, `channel candidate`, أو `partner/competitor hypothesis`.

### 1.2 الخدمة المقترحة بدقة

> **Nettoyage et contrôle de référentiels clients/fournisseurs pour migration vers la facturation électronique — sans saisie comptable ni conseil fiscal.**

النطاق الإداري/البياني المقترح:

1. فحص SIREN/SIRET من المصادر العامة عند توفرها؛
2. كشف السجلات المكررة؛
3. توحيد العناوين والحقول؛
4. كشف الحقول والبيانات الناقصة؛
5. تجهيز CSV/XLSX للاستيراد؛
6. إعداد تقرير قبل/بعد وسجل تغييرات؛
7. تمييز السجلات التي تحتاج قراراً من العميل؛
8. تسليم قائمة تحقق للاستيراد، دون تنفيذ قرار محاسبي نيابة عن العميل.

### 1.3 ما هو خارج النطاق

لا يشمل العرض، ولا يجوز أن يوحي بأنه يشمل:

- مسك الحسابات أو إدخال القيود؛
- الترميز أو imputation المحاسبي؛
- إعداد أو تقديم التصريحات الضريبية والاجتماعية؛
- اتخاذ قرارات TVA؛
- اختيار منصة معتمدة نيابة عن العميل؛
- إعداد نظام فوترة إلكترونية فرنسي؛
- استشارة قانونية أو ضريبية؛
- ضمان الامتثال؛
- الاتصال بعملاء العميل دون تفويض واضح؛
- معالجة بيانات شخصية خارج إطار تعاقدي مناسب.

أي طلب يتجاوز هذا الحد يُوقف ويُحال إلى خبير محاسبي أو محامٍ أو مختص GDPR بحسب الموضوع.

## 2. السياق السوقي المؤكد، دون تحويله إلى وعد مبيعات

تذكر المصادر الرسمية الفرنسية أن استقبال الفواتير الإلكترونية يصبح إلزامياً في 1 سبتمبر 2026، وأن إصدارها يصبح إلزامياً للمؤسسات الصغيرة والمتوسطة والميكرو-مؤسسات في 1 سبتمبر 2027: [Service-Public](https://entreprendre.service-public.gouv.fr/actualites/A18953) و[المديرية العامة للضرائب](https://www.impots.gouv.fr/professionnel/je-passe-la-facturation-electronique).

هذا يثبت وجود دافع تنظيمي عام للتحضير، لكنه **لا يثبت** أن أي prospect في القائمة يريد outsourcing من الجزائر، ولا يثبت استعداد أي جهة للدفع. السؤال التجاري الذي يجب اختباره هو: هل يشتري مكتب أو شريك تكامل Pilot محدوداً لتنظيف بيانات عملائه أو مورديه؟

## 3. مفتاح الحالات

| الرمز | المعنى | ما يجوز قوله |
|---|---|---|
| `PUBLIC_SIGNAL` | إشارة منشورة في صفحة عامة | «تظهر إشارة عامة إلى اهتمام/خدمة ذات صلة» |
| `QUALIFIED_PROSPECT_HYPOTHESIS` | ملاءمة أولية مبنية على الإشارة والحجم المحتمل | «مرشح يحتاج تحققاً» |
| `PARTNER_HYPOTHESIS` | قد يكون قناة أو شريكاً أو مكاملاً | «فرضية شراكة» |
| `COMPETITOR_HYPOTHESIS` | قد يبيع خدمة قريبة | «منافس أو شريك White-label محتمل» |
| `UNVERIFIED` | معلومة تحتاج تحققاً مباشراً | «غير متحقق» |
| `CONTACT_NOT_STARTED` | لم يحدث تواصل | «لم تبدأ المراسلة» |
| `DISCOVERY` | لا تُستخدم إلا بعد مقابلة موثقة | يجب إرفاق تاريخ ومصدر المقابلة |
| `PAID_PROOF` | لا تُستخدم إلا بعد عقد/فاتورة/دفعة موثقة | لا توجد حالياً |

الحالة الافتراضية لكل الصفوف أدناه: `PUBLIC_SIGNAL` + `CONTACT_NOT_STARTED`، ما لم يذكر خلاف ذلك. لا توجد صفوف `DISCOVERY` أو `PAID_PROOF` في هذه اللقطة.

## 5. البطاقات التفصيلية من البداية إلى النهاية

> لا تحتوي البطاقات على أسماء أشخاص أو عناوين بريد شخصية. يجب استخدام صفحة الاتصال العامة أو الدليل المهني والتحقق من الجهة قبل أي رسالة.

### 5.1 ARCOEX — الأولوية 1

- **الموقع المعلن:** Quint-Fonsegrives قرب Toulouse.
- **نوع الهدف:** مكتب محاسبة محلي؛ فرضية أول عميل Pilot.
- **الإشارة العامة:** أدوات رقمية وموضوع الفوترة الإلكترونية ظاهر في موقع المكتب.
- **المصدر:** [arcoex.fr](https://www.arcoex.fr/).
- **الملاءمة المفترضة:** مكتب محلي قد يملك قاعدة بيانات عملاء TPE ويحتاج عملاً إدارياً متكرراً قبل الترحيل.
- **ما لم يتحقق:** عدد العملاء، عدد السجلات، المنصة المستخدمة، وجود outsourcing، واسم صاحب القرار.
- **زاوية الاستكشاف:** «هل لديكم ملفات عملاء تحتاج تنظيفاً قبل الاستيراد؟» لا «نحن نضمن امتثالكم».
- **المخرج المطلوب من أول تواصل:** رد مكتوب أو إحالة إلى الشريك/مسؤول الإنتاج.
- **الحالة:** `PUBLIC_SIGNAL` / `CONTACT_NOT_STARTED`.

### 5.2 FQM Conseil — الأولوية 2

- **الموقع المعلن:** Toulouse / Blagnac.
- **نوع الهدف:** مكتب أو جهة مرافقة لـ TPE.
- **الإشارة العامة:** صفحة تعلن مهمة مرافقة مدير TPE في تنظيم مؤسسته استعداداً لإصلاح الفوترة الإلكترونية.
- **المصدر:** [صفحة المهمة](https://www.fqm-conseil.fr/details-expert-comptable+proposant+une+mission+d+accompagnement+du+dirigeant+de+tpe+dans+l+organisation+de+son+entreprise+en+vue+de+la+reforme+de+la+facturation+electronique+a+toulouse-178).
- **الملاءمة المفترضة:** يمكن أن تكون خدمة تنظيف البيانات مكوّناً إدارياً خلفياً لمرافقة قائمة.
- **ما لم يتحقق:** هل ينفذ المكتب التنظيف داخلياً، وهل يقبل موردين خارج فرنسا، وما حجم ملفات TPE.
- **زاوية الاستكشاف:** اقتراح Pilot على 20–50 سجلاً لا عرض شامل.
- **الحالة:** `PUBLIC_SIGNAL` / `CONTACT_NOT_STARTED`.

### 5.3 JF Occitanie — الأولوية 3

- **النطاق:** Nîmes، Sommières، Montpellier.
- **نوع الهدف:** شبكة/مكتب إقليمي يخدم عملاء صغاراً.
- **الإشارة العامة:** استعداد معلن للفوترة الإلكترونية وخدمة إقليمية متعددة المواقع.
- **المصدر:** [jfoccitanie.fr](https://jfoccitanie.fr/).
- **الملاءمة المفترضة:** قد يكون هناك حجم ملفات أكبر، لكن الوصول إلى مالك قرار واحد غير مضمون.
- **ما لم يتحقق:** عدد المكاتب، حجم قاعدة العملاء، الأدوات، ومسؤول onboarding.
- **زاوية الاستكشاف:** ابدأ بمكتب واحد أو فرع واحد، وليس الشبكة كلها.
- **الحالة:** `PUBLIC_SIGNAL` / `CONTACT_NOT_STARTED`.

### 5.4 RYDGE Conseil — الأولوية 4

- **الموقع:** Montpellier.
- **نوع الهدف:** مكتب/شبكة محاسبة.
- **الإشارة العامة:** مرافقة العملاء في الفوترة الإلكترونية.
- **المصدر:** [صفحة Montpellier](https://www.rydge.fr/cabinet-expert-comptable/expert-comptable-montpellier-34000).
- **الملاءمة المفترضة:** قد يحتاج فريق المرافقة إلى إعداد بيانات العملاء أو مورديهم.
- **ما لم يتحقق:** بنية الشراء، الموردون المعتمدون، وحجم ملفات TPE/PME.
- **زاوية الاستكشاف:** اسأل عن أكثر مرحلة onboarding استهلاكاً للوقت قبل ذكر السعر.
- **الحالة:** `PUBLIC_SIGNAL` / `CONTACT_NOT_STARTED`.

### 5.5 Finot & Associés — الأولوية 5

- **الموقع:** Lyon / Brignais.
- **نوع الهدف:** مكتب محاسبة لديه خطاب نظم معلومات/رقمنة.
- **الإشارة العامة:** صفحات عن إلزام الفوترة الإلكترونية، تدقيق نظم المعلومات وتدفقات الفوترة، وحاجة الشركات إلى مرافقة.
- **المصادر:** [صفحة الإصلاح](https://www.finotassocies.fr/details-facturation+electronique+obligatoire+2026+votre+expert-comptable+a+lyon+et+brignais+vous+accompagne-259) و[صفحة الحلول](https://www.finotassocies.fr/details-solution+de+facturation+electronique+pour+une+entreprise+a+lyon+faites-vous+accompagner+par+un+expert-221).
- **الملاءمة المفترضة:** أقرب من مكتب تقليدي إلى مشكلة جودة البيانات والتدفقات.
- **ما لم يتحقق:** هل يقدم المكتب هذه الخدمة داخلياً، وما إذا كان يقبل subcontracting خارجياً.
- **زاوية الاستكشاف:** جودة master data، لا «خدمة فوترة إلكترونية» عامة.
- **الحالة:** `PUBLIC_SIGNAL` / `CONTACT_NOT_STARTED`.

### 5.6 Groupe T2F Expert-Comptable — الأولوية 6

- **النطاق:** Toulouse / Paris.
- **نوع الهدف:** مكتب محاسبة متوسط؛ فرضية حجم ملفات أعلى.
- **الإشارة العامة:** صفحات مخصصة للفوترة الإلكترونية مع حضور إقليمي وفريق معلن في البحث السابق.
- **المصادر:** [صفحة Toulouse/Paris الأولى](https://www.groupe-t2f.eu/facture-electronique-expert-comptable-toulouse-paris) و[الصفحة الثانية](https://www.groupe-t2f.eu/expert-comptable-facture-electronique-toulouse-paris).
- **الملاءمة المفترضة:** يمكن اختبار Pilot واحد قبل التوسع إلى العملاء.
- **ما لم يتحقق:** حجم قاعدة البيانات، مسؤول القرار، وسياسة الموردين.
- **زاوية الاستكشاف:** «هل يوجد backlog تنظيف قبل الاستيراد؟» وليس «دعونا ننفذ الامتثال».
- **الحالة:** `PUBLIC_SIGNAL` / `CONTACT_NOT_STARTED`.

### 5.7 Cabinet Archipel — الأولوية 7

- **الموقع:** Lyon.
- **نوع الهدف:** مكتب محاسبة/شريك أدوات.
- **الإشارة العامة:** استخدام Pennylane وربط أدوات الإدارة والفوترة والمحاسبة.
- **المصدر:** [archipel-lyon.fr/pennylane-lyon](https://www.archipel-lyon.fr/pennylane-lyon).
- **الملاءمة المفترضة:** الترحيل والربط يخلقان حاجة إلى CSV منظم وحقول متسقة.
- **ما لم يتحقق:** هل يوجد مورد تنظيف حالي، وما شكل الاستيراد الفعلي.
- **زاوية الاستكشاف:** «جاهزية ملف الاستيراد» فقط.
- **الحالة:** `PUBLIC_SIGNAL` / `CONTACT_NOT_STARTED`.

### 5.8 Comexa — الأولوية 8

- **الموقع:** Lyon.
- **نوع الهدف:** مكتب صغير/متوسط.
- **الإشارة العامة:** موقع المكتب يعرض خدماته وموضوع الفوترة الإلكترونية.
- **المصدر:** [comexa.fr/le-cabinet](http://comexa.fr/le-cabinet).

- **زاوية الاستكشاف:** رسالة قصيرة إلى المكتب عبر قناة الاتصال العامة ثم متابعة واحدة.
- **الحالة:** `PUBLIC_SIGNAL` / `CONTACT_NOT_STARTED`.

## 7. الرسالة الأولى المقترحة بالفرنسية

### رسالة بريد قصيرة

```text
Objet : Préparation des données clients/fournisseurs — facturation électronique

Bonjour,

J’ai vu que [nom du cabinet] accompagne les entreprises sur la réforme de la facturation électronique.

Je teste actuellement un service administratif très limité : contrôle SIREN/SIRET, dédoublonnage,
normalisation des adresses, détection des champs manquants et préparation d’un fichier CSV d’import.

Il ne s’agit ni de saisie comptable, ni de conseil fiscal, ni de paramétrage de plateforme.

Avant de vous présenter une offre, puis-je vous poser une question : cette préparation des référentiels
clients/fournisseurs crée-t-elle actuellement une charge pour votre équipe ?

Si oui, je peux proposer un test limité sur 20 à 50 lignes, avec rapport avant/après, sans engagement
sur un projet plus large.

Bien cordialement,
[Nom]
``` 

### قواعد الرسالة

- لا تقل `client`؛ قل `cabinet ciblé` أو `prospect`.
- لا تقل `conformité fiscale garantie`.
- لا تعرض 300 سجل بسعر كبير في الرسالة الأولى.
- لا ترسل بيانات عميل حقيقية أو ملفاً سرياً.
- هدف الرسالة هو سؤال مشكلة، لا إغلاق بيع فوري.
- متابعة واحدة أو اثنتان كحد أقصى، ثم تسجيل النتيجة والتوقف.

## 8. Pilot محدود قبل أي عرض كبير

### نطاق Pilot

- 20–50 سجل؛
- بيانات عامة أو بيانات يختار العميل مشاركتها بعد NDA/DPA مناسب؛
- تقرير قبل/بعد؛
- CSV/XLSX؛
- قائمة المكررات؛
- قائمة الحقول الناقصة؛
- سجل تغييرات؛
- لا إدخال محاسبي؛
- لا نصيحة ضريبية؛
- لا ضمان امتثال.

### معيار قبول Pilot

لا يُعتبر Pilot ناجحاً إلا إذا وافق العميل كتابةً على:

1. شكل الملف؛
2. تعريف الحقول؛
3. نسبة السجلات التي تمت معالجتها؛
4. السجلات التي بقيت تحتاج قراراً؛
5. حقه في إيقاف التوسع؛
6. طريقة حذف أو إعادة البيانات.

السعر المقترح في هذه المرحلة **فرضية اختبار** وليس سعراً سوقياً مثبتاً. لا يُعرض مبلغ 1,450 يورو لـ300 سجل على أنه معيار سوق. ابدأ بحجم صغير، ثم اجمع دليلاً على الوقت والقبول والدفع.

## 9. GDPR والحدود القانونية ومسار الدفع

### 9.1 البيانات

نقل أسماء الأشخاص وبريدهم من الاتحاد الأوروبي إلى الجزائر قد يكون نقل بيانات خارج المنطقة الاقتصادية الأوروبية. الترتيب الأكثر تحفظاً:

1. العمل داخل بيئة العميل أو على ملف يفتحه العميل بوصول محدود؛
2. البدء ببيانات الشركات وSIREN/SIRET دون أسماء شخصية؛
3. عند الحاجة، DPA وبنود SCCs وضمانات تقنية بعد مراجعة مختص.

المراجع: [CNIL — clauses contractuelles types](https://www.cnil.fr/fr/clauses-contractuelles-types-entre-responsable-et-sous-traitant) و[CNIL — transferts hors UE](https://www.cnil.fr/fr/transferts-de-donnees-hors-ue-le-cadre-general-prevu-par-le-rgpd).

### 9.2 المهنة المحاسبية

يجب عدم تنفيذ أو تسويق مسك الحسابات أو إدخال القيود أو التصريحات على أنها خدمة تنظيف بيانات. الحد الفاصل القانوني يحتاج مراجعة مختص فرنسي قبل أول عقد، خصوصاً إذا كان العمل تحت مسؤولية مكتب محاسبة.

المراجع الأولية التي يجب عرضها على محامٍ/خبير محاسبي: [المادة 20](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000045178543/2026-09-21) و[حكم 4 أكتوبر 2022](https://www.legifrance.gouv.fr/juri/id/JURITEXT000046389206).

### 9.3 التحصيل من الجزائر

المسار الأساسي المفترض هو تحويل بنكي باليورو إلى كيان وحساب مقبولين لدى البنك الجزائري، بعد التحقق من التوطين والفوترة والتصدير الخدمي. يمكن اختبار [Grey](https://grey.co/en-dz) كخيار تقني، لكن قبول الحساب والاسم القانوني وإثبات مصدر الأموال يحتاج تأكيد البنك.

لا تجعل RedotPay المسار الأساسي لمكتب فرنسي: قد تكون بعض مساراته أقرب إلى crypto/stablecoin أو حساب شخصي، وهذا لا يناسب عرضاً مؤسسياً منظماً. راجع [التحويل الدولي](https://helpcenter.redotpay.com/en/articles/11325255-common-questions-about-international-transfer) و[استلام العملة المحلية](https://helpcenter.redotpay.com/en/articles/11388117-how-to-send-crypto-and-receive-local-currency) قبل أي استعمال، ولا تعد العميل به.

مراجع المسار الجزائري: [بنك الجزائر](https://www.bank-of-algeria.dz/les-exportateurs-disposent-100-recettes-leurs-exportations) و[المديرية العامة للضرائب](https://www.mfdgi.gov.dz/fr/professionnels/avantages-investissement/avantages-par-activite/avantages-fiscaux-accordes-a-lexportation). هذه مراجع بحثية وليست بديلاً عن محاسب أو بنك.

## 10. نموذج prospect sheet قابل للنسخ

| الحقل | القيمة المطلوبة |
|---|---|
| `prospect_id` | `FR-RFE-001` ... |
| `organization_name` | الاسم القانوني/التجاري كما في المصدر |
| `target_type` | مكتب / شبكة / منصة / مكامل / منافس محتمل |
| `priority` | A / B / C |
| `city_or_scope` | المنطقة المعلنة |
| `public_signal_url` | رابط الصفحة التي تبرر الإدراج |
| `contact_page_url` | صفحة الاتصال العامة فقط |
| `source_checked_at` | تاريخ التحقق |
| `public_signal_summary` | وصف محايد بلا مبالغة |
| `service_fit_hypothesis` | لماذا قد توجد الملاءمة |
| `unknowns` | ما لم يتحقق |
| `decision_maker_role` | الدور المستهدف، لا اسم شخص غير ضروري |
| `status` | `CONTACT_NOT_STARTED` / `REPLIED` / `DISCOVERY` / `DECLINED` / `PILOT_PROPOSED` / `PAID_PROOF` |
| `last_contact_date` | فارغ حتى يحدث تواصل |
| `response_evidence_url` | رابط/سجل موثق إن وجد |
| `data_scope` | عامة / شركات فقط / شخصية / غير محددة |
| `legal_review_needed` | نعم/لا + السبب |
| `payment_route_checked` | غير مختبر / قيد التحقق / مقبول / مرفوض |
| `next_action` | خطوة واحدة قابلة للتنفيذ |
| `stop_reason` | سبب التوقف إن وجد |

### حالات التواصل المسموحة

- `CONTACT_NOT_STARTED`: لم ترسل أي رسالة؛ وهذه حالة كل القائمة الحالية؛
- `SENT`: رسالة مرسلة مع تاريخ ونسخة؛
- `REPLIED`: رد فعلي محفوظ؛
- `DISCOVERY`: مقابلة أو مكالمة موثقة؛
- `PILOT_PROPOSED`: عرض Pilot أُرسل؛
- `PILOT_ACCEPTED`: موافقة مكتوبة على Pilot؛
- `PAID_PROOF`: عقد/فاتورة/دفعة موثقة؛
- `DECLINED`: رفض صريح؛
- `NO_RESPONSE_CLOSED`: أغلقت المتابعة بعد نافذة محددة.

لا يجوز تخطي الحالات أو ترقية `PUBLIC_SIGNAL` إلى `CUSTOMER` دون دليل تعاقدي/مالي حي.

## 11. معايير النجاح والتوقف

### بوابات اختبار السوق

1. بعد 30 رسالة موجهة: أقل من 3 محادثات حقيقية يعني أن القناة أو الرسالة ضعيفة.
2. بعد 10 محادثات: صفر طلب عروض يعني أن قيمة الخدمة أو الشريحة غير مناسبة.
3. بعد 5 عروض مخصصة: صفر Pilot مدفوع أو دفعة مقدمة يعني أن العرض غير مثبت.
4. لا تُبنى منصة أو أداة كبيرة قبل تجاوز بوابة الطلب.
5. لا يُكتب `CUSTOMER` أو `PAID_PROOF` قبل موافقة مكتوبة أو دفعة مسوّاة.

### شروط القتل الفوري

- طلب العميل أعمالاً محاسبية أو ضريبية؛
- رفض مسار GDPR أو عدم وجود أساس لمعالجة البيانات؛
- رفض البنك أو قناة الدفع دون بديل قانوني؛
- الحاجة إلى أسرار أو بيانات خاصة قبل وجود عقد؛
- عدم القدرة على تحديد صاحب قرار؛
- استخدام سعر أو غرامة أو حكم قانوني غير متحقق؛
- وجود تضارب بين صفحة عامة والحالة الحية؛
- محاولة وصف Pilot أو اهتمام عام بأنه عميل.
