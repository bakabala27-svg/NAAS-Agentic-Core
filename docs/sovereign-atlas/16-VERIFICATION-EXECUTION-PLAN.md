# 16 — خطة التحقق والتنفيذ: 72 ساعة / 30 يوماً / 90 يوماً / سنة / 5–10 سنوات + سيناريوهات رأس المال

> وثيقة مرجعية تحليلية ضمن [الأطلس السيادي](README.md) · مرتبطة بـ[النماذج المالية](15-FINANCIAL-MODELS.md) و[المسار القانوني](13-LEGAL-FINANCIAL-PATH.md) و[سجل الفرص](14-SCORING-MODEL.md).

---

## 1. أول 72 ساعة (فهرسة وفرز لا حماس)

| الساعات | المهمة | المخرج المكتوب |
|---|---|---|
| 0–8 | بناء **فهرس المصادر الحي** (List في سجل [18](18-REGISTRIES-SOURCES.md)) + تحميل/حفظ PDFs/صفحات المصادر الرسمية الكبرى ( الجمارك، بنك الجزائر، ONS، ITC قواعد عامة، قوانين مالية) | فهرس S-xx محدث بحالة كل مصدر |
| 8–20 | تحديد القطاعات ذات البيانات الأفضل (نتيجة: خدمات رقمية، غذاء معلّب، سياحة جنوب، خدمات مناجم — FACT بنية تحقق وBEST متوفر الآن) | قائمة القطاعات العشرة بدرجة قابلية التحقق |
| 20–36 | استخراج أول قائمة فرص (الـ20 في [14](14-SCORING-MODEL.md) جاهزة) + مراجعة FACT/HYPOTHESIS لكل منها | فرز تم: موثق/فرضية/سيناريو |
| 36–56 | اختيار **5 تجارب سريعة** بمعيار: تحقق <30 يوماً، تكلفة <500 دولار، بيع حقيقي محتمل | بطاقة تجربة: فرضية، مقياس نجاح، ميزانية |
| 56–72 | فتح قنوات: نماذج تواصل مشترين، حسابات مهنية، تحديد بنك ذي مكتب دولي، قائمة مخابر/شهادات | ورقة اتصالات معبأة |

**التجارب الخمس المقترحة للدورة الأولى (مطابقة قائمة العشرة في [17](17-RANKINGS-MANDATORY-OUTPUTS.md)):**
1. عرض خدمة تعريب/تقييم AI عربي لـ30 شركة نماذج/وسيط بيانات (OP-002).
2. عرض خدمة «مطابقة تصدير» لـ20 معصرة/مصنع تمور (OP-003).
3. صفحة هبوط + جمع إيداعات رحلة صحراوية (OP-004).
4. مقابلة 5 مشترين أوروبيين لتمور/زيتون بأسئلة مواصفات (فحص سعر حقيقي N-model).
5. عرض مسح درون لشركتين مقاولات/مناجم أو تعاونية كبرى (OP-009).

## 2. أول 30 يوماً (من الكلام إلى أرقام حقيقية)

- **مقابلات مشترين وخبراء:** ≥25 مقابلة (مشترون EU/خليج/إفريقيا حسب السلسلة + مصدرون جزائريون عاملون). مخرج: جدول مواصفات/شهادات/أسعار حقيقية يترقى بها HYPOTHESIS في النماذج [15](15-FINANCIAL-MODELS.md).
- **أسعار حقيقية:** عروض FOB فعلية لـ3 منتجات من نماذج B/C/G + أجور شحن بحري حاوية (خطوط جزائر-مارسيليا/برشلونة) + أسعار خام ميدانية (سوق الجملة).
- **التحقق القانوني:** كتابي من البنك (توطين/آجال تحصيل/نسبة احتفاظ عملة L-03) + محاسب (شكل الكيان) + قائمة قيود تصدير L-01.
- **عروض اختبار:** عرض شحن شحنة تجريبية صغيرة (LCL) أو عينة مجانية مدفوعة الشحن لـ3 مشترين؛ عرض خدمة رقمية مدفوع صغير (milestone) لا مجاني.
- **نماذج/عينات:** عبوة أولى (B/C/D) بملصق تجريبي مطابق (nutritional facts/لغات/باركود) + ملف مواصفة تقنية قابل للإرسال.
- **قنوات:** صفحات عروض تجارية ثنائية اللغة + حملة رسائل موجّهة (200 رسالة مخصصة/قناة) + تسجيل قاعدة بيانات مشترين في CRM بسيط.

**بوابة نجاح اليوم 30:** 🔑 ≥2 دليل طلب حقيقي (LOI/إيداع/طلب عينة بشروط) أو إعادة تصميم قائمة التجارب.

## 3. أول 90 يوماً (أول صفقة موثقة)

- تنفيذ **أول صفقة تجريبية أو عقد خدمة** بعملة أجنبية مدخولة نظامياً (تحويل بنكي موثق — إثبات المسار كله: توطين→تسليم→تحصيل→إعلان).
- توثيق: الكلفة الفعلية، الهامش المحقق، العوائق (زمن تأشيرة؟ رفض عينة؟ تأخر بنك؟) → **ورقة دروس* تُضاف لسجل التجارب [18](18-REGISTRIES-SOURCES.md)**.
- تحسين العرض: سعر/حجم/تغليف بحسب ردود 90 يوماً؛ بناء ملف «بائع موثوق» (شهادة+مراجع+سرعة رد).
- قاعدة مشترين ≥100 جهة مصنّفة (دولة/سلسلة/حجم/شروط دفع).
- **اختيار مسار أو مسارين للتوسع** بمعيار [النموذج /100](14-SCORING-MODEL.md) بعد تحديث درجات الثقة.

## 4. سنة واحدة (قناة تصدير متكررة)

1. شحنات/عقود متكررة (≥3 عملاء نشطون، تكرار طلبية واحدة على الأقل).
2. الشهادات الأساسية المكتسبة (حسب السلسلة: عضوي/GlobalGAP للزراعة، IOC للزيت، ISO للخدمات).
3. شبكة موردين موثقة (تعاونيات/مصانع/فرق) بعقود نوعية.
4. منتج/تقنية مملوكة أولى: علامة مسجلة INAPI+EUIPO أو SAAS أو مجموعة بيانات مرخصة.
5. رفع القيمة المحلية (نسبة التحويل/التعبئة/الخدمة داخل الجزائر مقاسة).
6. نظام قياس ومتابعة: لوحة مؤشرات (إيراد عملة شهري، تكرار، هامش، التزام قانوني، كربون/ماء) — يغذي الأطلس كل دورة.

## 5. خمس إلى عشر سنوات (تحول هيكلي)

- الانتقال الموصوف في [الملخص](00-EXECUTIVE-SUMMARY.md) §4: من مواد → منتجات وتقنيات (صلب متخصص، أسمدة متخصصة، علامات غذاء عالمية، سحابة إقليمية بعد F-08/F-25).
- تجمعات صناعية-علمية حول: صلب الحديد (تندوف-بشار-عنابة)، فوسفات (تبسة-سكيكدة-عنابة)، غذاء (غليزان-بجاية-الوادي-بسكرة)، لوجستيات العبور (تمنراست-الحدود).
- علامات جزائرية عالمية + منظومة ملكية فكرية (IG متعددة، براءات، تراخيص تصديرية).
- موقع الجزائر منصة إنتاج/خدمات بين إفريقيا وأوروبا (زلكاف×EU).

## 6. السيناريوهات الشخصية حسب رأس المال (لا افتراض لميزانيتك — اختر مسارك)

### س1: رأس مال شبه معدوم (0–500 دولار)
| العنصر | المحتوى |
|---|---|
| الفرص | OP-001 خدمات رقمية، OP-002 بيانات/تقييم AI، OP-011 بحث سوق مدفوع، وساطة تجارية قانونية (عمولة مكتوبة) |
| المهارة المطلوبة | لغة ثانية تقنية + مادة واحدة قابلة للبيع (انظر [14](14-SCORING-MODEL.md) بطاقات) |
| أول عميل محتمل | شركة فرنكوفونية صغيرة/وسيط بيانات AI/مصدّر جزائري يحتاج ملف تصدير |
| العرض الأول | مخرج مدفوع صغير (<300 دولار) مضمون خلال 7 أيام (مدخل ثقة) |
| الوصول للعميل | LinkedIn مخصص 20 رسالة/يوم + منصات أعمال + شبكة جالية |
| نموذج رسالة | «أنا [الاسم] من الجزائر. لاحظت أن [مشكلته]. أنجز لك [مخرج محدد] خلال 7 أيام مقابل [سعر] مضمون بالقبول. [دليل كفاءة]. هل أرسل النموذج؟» |
| التسليم/التحصيل | تسليم رقمي؛ تحويل بنكي لكيان نظامي ([فصل 13](13-LEGAL-FINANCIAL-PATH.md) §4) أو منصة بوساطة |
| تجربة 7 أيام | 140 رسالة مخصصة + 3 عروض مكتوبة + أول مخرج مجاني-عينة محدودة جداً |
| تجربة 30 يوماً | ≥1 عميل مدفوع + دراسة حالة منشورة + رفع سعر 20% |
| شروط التوسع | 3 عملاء متكررون → توظيف أول متعاون + فتح SAAS لاحقاً |

### س2: رأس مال صغير (0.5–15 ألف دولار)
- مسارات: OP-009 مسيّرات، OP-004 سياحة (موسم)، تغليف تعاقدي صغير (استئجار خط), تجميع فريق خدمات 2–3 أشخاص.
- نفس هيكل الجدول أعلاه مضافاً إليه: تأمين معدات، رخص (درون/وكالة سفر)، صفحة عروض ثنائية، حضور معرض واحد إقليمي افتراضي/حضوري جزئي.
- بوابة التوسع: عائد شهري ≥ 3× تكاليف التشغيل لثلاثة أشهر متتالية.

### س3: رأس مال متوسط (15–150 ألف دولار)
- مسارات: OP-006 زيوت أساسية، OP-007 تمور (موسمية مع تمويل عامل)، OP-015 ملح، محطة تجميد/تبريد صغيرة بالشراكة.
- إضافات: مخبري معتمد (أو تعاقد)، شهادات، محاسب دولي جزئي، CAGEX عند تصدير ائتماني ([قانوني](13-LEGAL-FINANCIAL-PATH.md) §7).
- بوابة: سعر تحقق فعلي ضمن نطاق (أ) من [15](15-FINANCIAL-MODELS.md) قبل تجديد الاستثمار.

### س4: رأس مال مرتفع (>150 ألف دولار)
- مسارات: تعميق سلاسل B/C/G بمهاد مصنع، OP-013 هياكل شمس (تسجيل مناقصات محتوى محلي)، OP-012 كابلات (شراكة تقنية)، منصات B2B بفريق كامل.
- قواعد حاكمة: لا CAPEX قبل LOI/عقد مرجع واحد مكتوب على الأقل · تعرفة/تراخيص مكتوبة لا شفهية · مراجعة محامٍ دولي لأي شراكة أجنبية ([قانوني](13-LEGAL-FINANCIAL-PATH.md) §2).

## 7. آلية التقارير للأطلس (كل تجربة تُغذي الوثيقة)
