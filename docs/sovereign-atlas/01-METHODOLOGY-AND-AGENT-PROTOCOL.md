# 01 — المنهجية، درجات الثقة، وبروتوكول وكلاء الذكاء الاصطناعي

> وثيقة مرجعية تحليلية ضمن [الأطلس السيادي](README.md) · الحالة: LIVE-REFERENCE · **إلزامية القراءة قبل أي تعديل على هذا الأطلس**.

---

## 1. الدقة قبل الحماس: درجات الثقة السبع

كل معلومة في الأطلس موسومة بواحدة من الدرجات التالية. لا يجوز رفع درجة معلومة دون دليل أقوى مذكور صراحة.

| الوسم | المعنى | شروط الاستبدال/الترقية |
|---|---|---|
| `FACT` | حقيقة موثقة | مصدر رسمي أو أولي مذكور (اسم، رابط، تاريخ نشر، تاريخ اطلاع). تُشطب فقط بمصدر رسمي أحدث يعارضها، ويُسجَّل التعارض. |
| `GOV-EST` | تقدير رسمي | رقم من جهة حكومية/مؤسسة وطنية (وزارة، بنك مركزي، ديوان إحصاء). يُعامل كأفضل تقدير متاح مع الإشارة لاحتمال التحيز السياسي. |
| `IND-EST` | تقدير مستقل | منظمات دولية (FAO، البنك الدولي، ITC، IEA، مراكز أبحاث) أو شركات مدرجة ملزمة بالإفصاح. |
| `ANALYSIS` | استنتاج تحليلي | اشتقاق منطقي/حسابي من مصادر أعلاه؛ الافتراضات مذكورة في موضعها. |
| `HYPOTHESIS` | فرضية تحتاج اختباراً | معقولة لكن بلا دليل كافٍ؛ يجب ربطها بتجربة تحقق في [خطة التحقق](16-VERIFICATION-EXECUTION-PLAN.md) أو نقلها لسجل الفجوات. |
| `SCENARIO` | سيناريو مستقبلي | إسقاط مشروط مُعلن كسيناريو؛ منع بات حذف وسم SCENARIO واعتباره توقعاً. |
| `MISSING` | معلومة مفقودة | لم يوجد مصدر موثوق؛ تُسجَّل فوراً في سجل الفجوات مع طريقة جمعها المقترحة. **لا يجوز ملء MISSING برقم «تقريبي» غير موسوم.** |

### قواعد الأرقام
- كل رقم مهم يرفق بـ: **المصدر + تاريخ النشر + الوحدة + النطاق الجغرافي + درجة الثقة**.
- النطاقات («أ» إلى «ب») إلزامية عند الشك؛ الدقة الزائفة (مثل «238,417 طناً» من تقدير) **خطأ منهجي**.
- الأرقام المالية تذكر عملتها وسنة أساسها (دولار 2024، دينار 2025…).

## 2. الشمول المنهجي لا الادعاء المطلق

1. التصنيف الشامل للأصول موجود في [README — الفهرس](README.md) ويفكك إلى 14 قطاعاً (فصول 03–11) مضافاً إليها الأسواق (12) والقانون (13).
2. **قائمة تحقق التغطية** في نهاية هذا الملف (§7) تُعلَّم حالة كل خلية: ✅ مغطاة · ◐ مغطاة جزئياً · ☐ فجوة.
3. كل خلية ☐ أو ◐ يجب أن تقابلها بطاقة في **سجل الفجوات** ([18](18-REGISTRIES-SOURCES.md)) تتضمن: ما ينقص، أثره، طريقة جمعه (مسح ميداني / تحليل مخبري / رأي قانوني / دراسة جدوى)، ومن يقدر على جمعه.

## 3. إحلال الواردات: قاعدة الفصل الصارمة

إحلال الواردات **ليست إيراداً تصديرياً**. يُحسب في الأطلس تحت بند مستقل: «حماية احتياطي العملة» بمقياس `imports_displaced_usd`، ولا يدخل أبداً في مجموع «الإيرادات الدولية» لأي فرصة أو لأي قائمة مرقمة. منتج أحللنا به واردات ثم صدّرنا فائضه يُحسب فائضه المصدَّر فقط.

## 4. القيمة المضافة قبل الخام: سلم التصعيد العشاري

لكل مورد تُفحص 10 مستويات بالترتيب، مع تسجيل أين تقف الجزائر اليوم وأين يجب أن تصل:

1. تصدير خام → 2. فرز/تنقية محلية → 3. مادة وسيطة → 4. منتج نهائي → 5. تصنيع معدات وخدمات الإنتاج → 6. برمجيات وبيانات وتقنيات حوله → 7. ترخيص تقنية ومعرفة → 8. إعادة تدوير واسترجاع مواد → 9. علامة تجارية وقناة توزيع عالمية → 10. منظومة بحث وتكوين واعتماد مهني تخدم القطاع وتُصدَّر هي نفسها.

> القاعدة: **لا توصية بالاستقرار عند المستويين 1–2** لأي مورد تتوفر فيه جدوى المستوى 4+ خلال 5 سنوات، ما لم يكن خاماً استراتيجياً ندراً يحقق أسعاراً احتكارية (مثال محتمل: غاز/فوسفات عالي الجودة — ويُثبت لا يُفترض).

## 5. الاستدامة والسيادة: معايير الاستبعاد (Kill-Criteria)

تُستبعد الفرصة أو تُعاد هيكلتها إذا انطبق عليها أيٌّ من:
- استنزاف مياه (خاصة جوفية غير متجددة) أو تربة دون تعويض موثق.
- تلوث مرتفع بلا خطة معالجة ممولة ضمن النموذج المالي.
- تدمير تنوع بيولوجي أو ساحل أو موقع تراثي.
- عمالة غير آمنة أو استغلالية أو تشغيل أطفال.
- بيع مورد استراتيجي بأقل من قدر ممكن (يُقاس بمقارنة سلم التصعيد §4).
- نقل معظم القيمة للخارج دون نقل معرفة/تشغيل محلي موثق في العقد.
- تعارض مع قانون جزائري أو قوانين أسواق الهدف (مثال: معايير الاتحاد الأوروبي الصحية، CBAM، عقوبات دولية).
- اعتماد على فساد أو تهريب أو تضليل أو تحايل على الصرف/الجمارك/الضرائب. **لا توجد استثناءات.**

## 6. الفصل بين مستويات الفرص (إلزامي في كل بطاقة)

| المستوى | الرمز | أمثلة من هذا الأطلس |
|---|---|---|
| فرد مستقل | IND | تسويق تصدير، تعريب، مسح بالمسيّرات، وساطة |
| شركة ناشئة | ST | SAAS تتبع غذائي، منصة مشترين، تقنية زراعية |
| مؤسسة صغيرة/متوسطة | SME | تغليف تمور، مقصب رخام، معاصر زيتون معتمدة |
| شركة صناعية كبيرة | LRG | أسمدة متخصصة، زجاج تعويم، كابلات |
| شراكة عام-خاص | PPP | محطات شمسية، تحلية، لوجستيات موانئ |
| سيادية/وطنية كثيفة رأس المال | SOV | سكك الحديد، أمونيا خضراء، مركز حوسبة وطني |
| بحثية طويلة الأجل | RES | ليثيوم/أرضية نادرة، تقنيات CCS، التكنولوجيا الحيوية البحرية |

> تُمنع صياغة «مشروع منجمي للفرد». حول كل SOV/LRG تُستخرج طبقات IND/ST/SME: قياس، صيانة، تدريب، تحليل، توثيق، هندسة، قطع غيار، جودة، بيانات (منهج «الفرص غير المباشرة» خماسي المستويات: المورد → التحويل → المعدات → الخدمات/البرمجيات → التعليم والاعتماد والملكية الفكرية).

## 8. بروتوكول وكلاء الذكاء الاصطناعي (12 قاعدة إلزامية)

على كل وكيل يعمل على هذا الأطلس أن:

1. **يقرأ الفهرس ([README](README.md)) وسجل القرارات (أسفل هذا الملف) قبل البدء.**
2. يحدد صراحة في أول مخرجاته: **القطاع، المنطقة، الفرضية (HYPOTHESIS) التي يختبرها**.
3. لا يكرر بحثاً سابقاً دون مبرر مكتوب (مصدر أحدث، شك في المنهجية، تغطية فجوة).
4. لا يغيّر نتيجة موسومة `FACT/GOV-EST/IND-EST` دون دليل أقوى + تسجيل التعارض في سجل التعارضات ([18](18-REGISTRIES-SOURCES.md)).
5. يذكر في نهاية عمله: **حدود بحثه وما لم يستطع تغطيته**.
6. يضيف كل فرصة جديدة إلى [السجل الموحد للفرص](14-SCORING-MODEL.md) بالبطاقة الإلزامية (§9) ولا يصفها نثراً فقط.
7. يربط كل فرصة بـ: **مصدر + سوق مستهدف + عميل محتمل مسمّى بنوعه** (لا «أوروبا تشتري» بل «مستوردو HS-0804.10 في فرنسا/ألمانيا»).
8. يحدّث **سجل الفجوات** بكل MISSING صادفه.
9. يسجّل **التعارضات بين المصادر** بدل اختيار ما يناسب السرد.
10. يفصل دائماً بين مستويات الفرص (§6) ولا يخلط SOV مع IND.
11. **لا يوصي بالتنفيذ** قبل فحص: القانون ([13](13-LEGAL-FINANCIAL-PATH.md))، البيئة (§5)، والوحدة الاقتصادية ([15](15-FINANCIAL-MODELS.md)).
12. يختم دورته بثلاثة أسطر: **أهم اكتشاف · أهم شك · أعلى إجراء تالٍ من حيث الأثر** في سجل الجلسات (أسفل هذا الملف).

## 9. بطاقة الفرصة الإلزامية (القالب)

يُلزم كل إدخال في سجل الفرص بهذا القالب (مثال مملوء في [14](14-SCORING-MODEL.md)):

| الحقل | الوصف |
|---|---|
| ID + الاسم | OP-### + اسم عملي |
| المستوى | IND/ST/SME/LRG/PPP/SOV/RES |
| الأصل المرتبط | من قائمة المخرجات 100 |
| درجة المورد على سلم التصعيد | 1→10 (§4) الآن والهدف |
| وصف المنتج/الخدمة | قابل للبيع، بمواصفة، لا شعار |
| العميل الدولي المستهدف | نوع+جغرافيا+قناة وصول |
| المنافسون | إقليمي ودولي بأسماء عملية |
| ميزة الجزائر | لماذا نحن؟ (تكلفة/جودة/قرب/ندرة) |
| رمز/رموز HS | عند التصدير السلعي |
| الأسواق المستهدفة | ببلدان، مع اتفاقية تجارية إن وجدت |
| رأس المال التقديري | نطاق + عملة |
| الزمن لأول إيراد | تقدير موسوم |
| الإيراد الأجنبي السنوي الممكن | متحفظ/أساسي/متفائل (نطاقات!) |
| الهامش والتوظيف | تقدير موسوم |
| المخاطر القانونية | من فصل 13 |
| الضريبية/الجمركية | من فصل 13 |
| البيئة/الماء/الطاقة | فحص §5 |
| المهارات المطلوبة | محلية أم تحتاج استقداماً |
| المستوى التقني | ناضج/متوسط/حديث |
| سلسلة القيمة | أين نقف وأين نلتقط القيمة |
| جودة البيانات | FACT…MISSING + ما يلزم للترقية |
| النتيجة /100 | من نموذج [14](14-SCORING-MODEL.md) بالأوزان المعلنة |
