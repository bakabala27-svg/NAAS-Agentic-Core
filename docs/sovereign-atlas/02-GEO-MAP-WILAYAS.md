# 02 — المسح الجغرافي المجهري: الأقاليم الأربعة وبطاقات الولايات الـ58 وخريطة التكامل

> وثيقة مرجعية تحليلية ضمن [الأطلس السيادي](README.md) · درجات الثقة في [المنهجية](01-METHODOLOGY-AND-AGENT-PROTOCOL.md) · القرار AD-02: بطاقات مكثفة (لا مطوّلة) مع سجل فجوات ميدانية.

## 1. الأقاليم الكبرى الأربعة (تحليل تكتيكي)

### 1.1 الساحل (16 ولاية ساحلية تقريباً + عمق قريب)
- **الأصول:** 1,200+ كم ساحل (MISSING: طول دقيق بمعايير موحدة — F-05)، موانئ تجارية رئيسية (الجزائر، وهران، عنابة، بجاية، سكيكدة، أرزيو، مستغانم، جيجل، غزوات)، تحلية مياه (هدف وطني 5.6 مليون م³/يوم بحلول 2030 `GOV-EST` S-09)، جامعات كبرى، كثافة سكانية ومهارات، ألياف وكابلات بحرية.
- **القيود:** ضغط عمراني، مياه شرب تاريخياً شحيحة (مخففة الآن بالتحلية)، تلوث بحري موضعي، زحف على الأرض الزراعية.
- **الدور في الأطلس:** بوابة التصدير + الصناعة الخفيفة والخدمات + الاقتصاد الأزرق + السياحة الساحلية المنظمة.

### 1.2 الهضاب العليا
- **الأصول:** حبوب وبقوليات (سهوب)، أغنام (ثروة صوف وجلود ولحوم)، تبني جافّة وشعير، شطوط (ملح محتمل)، رياح جيدة موضعياً، قرب من شرق/غرب البلاد.
- **القيود:** تصحّر زاحف، ندرة مياه موسمية، هجرة داخلية، بنية تحويل ضعيفة.
- **الدور:** أمن غذائي حيواني + أعلاف + طاقة رياح + محطة برية نحو العمق الإفريقي.

### 1.3 الجنوب الكبير (الشمال الصحراوي: ورقلة، الوادي، غرداية، الأغواط، بسكرة…)
- **الأصول:** محروقات (حاسي مسعود/حاسي الرمل) — قلب الاقتصاد الحالي `FACT`، أفضل إشعاع شمسي وطني، نخيل واحات (دقلة نور)، فوسفات (تبسة/جبل العنق وبلع الهضبة)، خطوط نقل جديدة.
- **القيود:** حرارة قصوى، مياه جوفية غير متجددة فعلياً (تُعامل كرأس مال لا دخل — معيار استبعاد)، بُعد لوجستي.
- **الدور:** تمويل التنويع + منصة أسمدة/طاقة/تمور التصديرية.

### 1.4 الصحراء الكبرى والجنوب الأقصى (تمنراست، جانت، إليزي، تندوف، أدرار، برج باجي مختار، عين قزام، عين صالح، تيميمون، بني عباس، المنيعة)
- **الأصول:** إشعاع شمسي من الأعلى عالمياً `HYPOTHESIS→GOV-EST`، تندوف: حديد غار جبيلات (3.5 مليار طن `FACT` S-04)، هوغار: ذهب صغير قائم + مؤشرات معادن (تنقيب، لا تأكيد اقتصادي)، سياحة صحراوية عالمية المستوى (طاسيلي ناجّر/الأهقّار — تراث عالمي)، الطريق العابر للصحراء نحو النيجر/نيجيريا، مياه جوفية ضخمة لكن محدودة التجدد.
- **القيود:** ماء، طاقة نقل، عزلة، أمن حدودي موضعي، حساسية بيئية وثقافية قصوى.
- **الدور:** التعدين الوطني، الطاقة الشمسية، السياحة العالية القيمة، البوابة الإفريقية العلنية عبر الزلكاف (ZLECAF).

## 3. خريطة التكامل بين الولايات (سلاسل قيمة عبرية)

> الفكرة: مورد في ولاية + جامعة/بحث في أخرى + مصنع في ثالثة + ميناء في رابعة = سلسلة تصدير واحدة.

```
[سلسلة الحديد والصلب]
تندوف(خام غار جبيلات) → سكة 950كم → بشار(فرز أولي) → (طاقة: شمس أدرار/الجنوب)
   → عنابة/الحجار + العاصمة(هندسة) + جيجل/بجاية(خدمات ميناء) → عنابة/أرزيو(تصدير)

[سلسلة الفوسفات والأسمدة]
تبسة(بلع الهضبة/جبل العنق) → معالجة تبسة/سكيكدة(كيمياء قائمة)
   → جامعات سطيف/قسنطينة(بحث أسمدة متخصصة/تربة) → عنابة ميناء CHEC(تصدير 2027) S-06

[سلسلة دقلة نور العالمية]
بسكرة(IG تولقة)+الوادي+تقرت+أولاد جلال+المغير(إنتاج) → غرداية/البليدة(تعبئة/تقنيات تجفيف)
   → تيزي وزو/العاصمة(علامة+تسويق) → موانئ العاصمة/عنابة/وهران(تصدير أوروبا/الخليج)

[سلسلة زيت الزيتون]
بجاية/تيزي وزو/غليزان/جيجل/سوق أهراس(إنتاج) → غليزان/سطيف(معاصر معتمدة/تعبئة)
   → مخابر العاصمة/وهران(جودة IOC) → مستغانم/وهران/بجاية(شحن) → الخليج/أمريكا/أوروبا

[سلسلة الأعشاب الطبية والتجميل]
المسيلة(بغاوس)+خنشلة(أوراس)+البليدة/تيبازة(زهر) → تقطير محلي معتمد
   → مخابر جامعية(تحليل) → علامات تجميل طبيعي (البليدة/العاصمة) → أوروبا/الخليج

[سلسلة الطاقة الشمسية و«الإلكترون المصنَّع»]
أدرار/تيميمون/تندوف(إشعاع) → تصنيع هياكل/كابلات (سطيف/البوريرة/وهران)
   → محطات وطنية (Solar 1000/3GW) + سعة فائضة → تحلية الساحل + ألمنيوم/زجاج/هيدروجين كثيف الطاقة

[سلسلة الصحراء السياحية]
جانت/تمنراست/إليزي/تيميمون/بني عباس (مواقع) → جامعات/وكالات العاصمة (حجز/تسويق/تأشير)
   → مطارات جانت/تمنراست (تأشيرة وصول للجنوب عبر وكالات معتمدة S-13)

[سلسلة الملح والكيمياء البحرية]
الساحل (شطوط/أحواض بحرية: وهران/مستغانم/الطارف/أدرار الداخلية) → تنقية/تعبئة
   → كلور-قلويات/ملح غذائي ميودّ → صناعة غذائية وطنية + تصدير إفريقيا

[سلسلة الزلكاف للساحل الإفريقي]
مصانع الشمال (أغذية/إسمنت/مواد بناء/أدوية) → الطريق العابر للصحراء
   → عين قزام/برج باجي مختار/تمنراست (لوجستيات/ZFCI) → النيجر/مالي/نيجيريا (مدفوعات مهيكلة: فصل 13)

[سلسلة الاقتصاد الأزرق]
بجاية/جيجل/عنابة/مستغانم/وهران/الطارف (صيد+موانئ) → تجميد/تعليب محلي
   → مخابر جودة → تصدير تونس/إيطاليا/إسبانيا + إعادة تدوير مخلفات الصيد (علف/جيلاتين)

[سلسلة الرقمية (لا حدود داخلية)]
جامعات (العاصمة/وهران/قسنطينة/سطيف/تيزي وزو) → مواهب → شركات ناشئة/أفراد
   → كابلات بحرية (العاصمة/عنابة/وهران) → أسواق فرنكوفونية/عربية/أفريقية عن بُعد
```
